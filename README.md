# emitech-midia

Imagens e vídeos dos posts do Instagram da Emi Tech (@emitechsistemas), servidos
pelo GitHub Pages para que a API do Instagram (via Windsor.ai) consiga buscá-los na
hora de publicar.

- Só entra aqui mídia de post **já aprovado pelo Eric** para publicação.
- A rotina `publicador-instagram-emitech` sobe os arquivos em `posts/<id>/` minutos
  antes do horário e publica em seguida.
- Nada de rascunho, dado de cliente, credencial ou material interno.

Plano e regras: `emitech-brain/10-empresa/PLANO_INSTAGRAM_EMITECH.md` (repositório privado).
